# Selected unit rawcode query

Source evidence recorded before implementation: WHT/native/gameplay_commands.hpp #ufind/#ufinds around1498 and WHT-1.29/native/gameplay_commands.hpp around1311 parse a query token, read only the active selected unit and its position, and report Found[term] or not found in active selection. Neither enumerates the map. This port adds #ufind rawcode only, keeps the active-selection scope, and fixes the reference false-positive by comparing actual rawcode. #ufinds name search is not enabled without a verified name reader. Rawcode input accepts four printable ASCII bytes or exact0xXXXXXXXX via existing parser. Uses existing verified UnitInfo131 rawcode/position reader plus original registry identity/world/local validation from RemoveUnit131 before and after native reads. No unverified native offsets or new writes.

Runtime uses existing per-build native identity and position guards; no new native offsets.
