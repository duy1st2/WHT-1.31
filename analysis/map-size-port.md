# Map size comparison port

References read: WHT/native/runtime.cpp ApplyMapSizeLimit (all3 preflight, cap7FFE0000, rollback), #mapsize and lifecycle; WHT-1.29/native/parity_hooks129.inl parityMapSize129 and independent preflight; parity_commands129.inl toggle. Hash evidence in map-size-evidence.json. No reference project changed.

Four independent1.31 profiles identify original unsigned256MiB comparisons. x86 has3 sites corresponding to generic read/allocation and two archive-parser size checks, with the same zero/size tests and subsequent allocation/context setup as1.29. x64 maps one generic64-bit file-loader CMP RAX / JBE check, followed by size storage/allocation and error33. Other occurrences of10000000 are enum/bitflag/varint comparisons and deliberately excluded. Full surrounding16-byte and96-byte guard windows include branch/allocation context and normalized x86 PE HIGHLOW relocations. No guard splits a relocation. See map-size-native-disassembly.log. These are file/archive guards, not proof of Battle.net map transfer support; other format/network limits remain.

Compared with reference immediate rewriting, the port uses a typed-by-instruction compare detour: x86 CMP EAX,7FFE0000 or x64 CMP RAX,7FFE0000, then indirect JMP to the instruction immediately after the original CMP. No stack or general register is modified; flags come only from CMP. MinHook manages affected thread IPs during enable/disable. Stubs are initializedRW then protectedRX and instruction cache flushed. They and disabled hook records stay allocated for process lifetime, avoiding freeing an in-flight continuation. No native image bytes are executed in automated tests.

All sites are checked before any enable. Partial enable failure attempts restoration of all owned sites. OFF/auth loss/settings loss restores native comparisons, even without a valid current profile. A foreign branch modification refuses restoration; no foreign bytes are overwritten. Config defaultsOFF and survives ordinary match/UI teardown. Polling occurs before the no-UI return, at most once/second, and immediately on enabled-state change; #mapsize applies immediately after checked persistence/reload. Profile refusal prevents enabling persistence; a post-save application failure is reported as such.

Tests verify the exact captured comparison and complete surrounding guards for all profiles, ASLR normalization, tampered contexts and final-site preflight refusal. Actual MinHook runs only on purpose-written owned RX functions to test inclusive boundaries, high64-bit inputs, flags/continuation, page protection restoration, disable/re-enable and foreign branch ownership. Pure group callbacks cover preflight/no writes and rollback; command tests cover strict input and checked persistence/reload/application errors. Actual client load of a large map and multiplayer behavior remain unverified.
